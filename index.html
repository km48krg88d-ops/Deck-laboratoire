Ventilateur
Face supérieure : toucher le logo pour sélectionner, écarter deux doigts pour déployer les pales, rapprocher pour les refermer. La jauge sur l’arête droite commande les 3 vitesses dans chaque sens (centre = arrêt). Double toucher sur la forme ouverte : mode silencieux. Retour au logo après 5 s sans action.
Lumières
Toucher une lampe pour la sélectionner (sans effet visuel). Écarter / rapprocher deux doigts pour régler son intensité. Après 5 secondes sans pincement : désélection.
